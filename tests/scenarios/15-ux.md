# T6.10 — UX 메시지 정확성 + skip prompt 시나리오

## 검증 대상 메시지 (spec §8.2 표)

| 상황 | 기대 메시지 |
|---|---|
| `.disabled` ON | `ℹ️ backward 비활성화 (재활성화: /vis-backlink-toggle on)` |
| vis daemon down | `⚠️ vis daemon 응답 없음 — backward 생략 (visd start 후 재시도)` |
| heuristic proceed | `🔗 backward dispatched — Top 5 평균 X.XX, N건 대상 (job=...)` |
| heuristic skip 추천 | `⚠️ backward skip 추천 — <근거>. 강제 진행? [y/N]` |
| 사용자 N/Enter | `ℹ️ backward skip 확정 (사용자)` |
| 사용자 y (override) | `🔗 backward dispatched — ... (user_override)` |
| Top 5 일부 dirty | `🔗 backward dispatched — N건 대상 (M건 dirty skip)` |
| 직전 job 대기 | `⏳ 선행 backward job 대기 중 (5초 max)` |
| subagent crash 정리 | `🧹 crashed job 자동 정리: <job_id>` |

## 검증 절차

각 시나리오별로 실제 호출 후 메시지가 위 표와 일치하는지 확인.

### Skip → N (Enter) 검증

1. S5 veto 발화 조건 만족 (draft-note.md 사용)
2. prompt 에서 Enter 입력
3. 기대: `ℹ️ backward skip 확정 (사용자)` 출력

- [ ] 메시지 텍스트 정확히 일치
- [ ] state history/ 에 `phase: user_skipped` 기록 확인

### Skip → y (override) 검증

1. S5 veto 발화 조건 만족 (draft-note.md 사용)
2. prompt 에서 `y` 입력
3. 기대: `🔗 backward dispatched` 메시지 + `reason: user_override_skip`

- [ ] dispatched 메시지 출력됨
- [ ] state JSON `reason` 필드에 `user_override_skip` 포함

### Proceed (dirty 일부) 검증

1. Top 5 X 중 1개 dirty 상태 만들기: `echo "dirty" >> /tmp/vault-test/003-RESOURCES/bar.md`
2. A = 새 노트 (S4·S5 미발화)
3. 기대: `(1건 dirty skip)` 포함 메시지

- [ ] `(N건 dirty skip)` 표현 메시지에 포함
- [ ] 복구: `cd /tmp/vault-test && git checkout -- 003-RESOURCES/bar.md`

### Proceed (정상) 검증

- [ ] `🔗 backward dispatched — Top 5 평균 X.XX, N건 대상 (job=...)` 형식 일치
- [ ] job_id 형식: `YYYYMMDD-HHMMSS-<basename>` 패턴
